# Mermaid Vision

高機能なMermaid図プレビュー拡張機能 - ズーム、パン、自動フィット、高解像度エクスポートに対応したVSCode拡張機能です。

## 機能

- **Mermaidコードのリアルタイムプレビュー**: マークダウンファイルや任意のテキストファイル内のMermaidコードを即座に可視化
- **柔軟なコード検出**:
  - マークダウンコードブロック（\`\`\`mermaid ... \`\`\`）に対応
  - `.mmd`ファイル全体をサポート
  - 選択範囲のMermaidコードをプレビュー
  - カーソル位置のMermaidブロックを自動検出
- **マウス操作でのアクセス**:
  - CodeLens（コードブロック上のクリック可能なリンク）
  - コンテキストメニュー（右クリックメニュー）
  - エディタタイトルバーのアイコンボタン
- **インタラクティブなプレビュー**:
  - 自動フィット表示（初期表示で最適なサイズに調整）
  - マウス位置を中心としたズーム機能（最大20倍）
  - スムーズなパン機能（ドラッグで移動）
  - リセットボタンで初期状態に戻す
- **高品質エクスポート機能**:
  - SVG形式でエクスポート（ベクター形式）
  - 高解像度PNG形式でエクスポート（4倍解像度）
- **最適化されたレンダリング**:
  - ガントチャートの日付重なり防止
  - 大きな図でも読みやすいフォントサイズ
- **クロスプラットフォーム対応**: Windows、macOS、Linux、WSLで動作

## 使い方

### 1. 基本的な使い方

1. Mermaidコードを含むファイルを開く
2. 以下のいずれかの方法でプレビューを表示:
   - **ショートカットキー**:
     - Windows/Linux: `Ctrl+Shift+M`
     - macOS: `Cmd+Shift+M`
   - **コマンドパレット**: `Ctrl+Shift+P` (macOS: `Cmd+Shift+P`) → "Mermaid: Preview Diagram" を選択
   - **CodeLens**: Mermaidコードブロックの上に表示される「👁 Preview」リンクをクリック
   - **コンテキストメニュー**: エディタ内で右クリック → "Mermaid: Preview Diagram" を選択
   - **エディタタイトルバー**: 👁アイコンをクリック

### 2. 対応するコード形式

#### マークダウンコードブロック

\`\`\`markdown
\`\`\`mermaid
graph TD
    A[開始] --> B{条件}
    B -->|Yes| C[処理1]
    B -->|No| D[処理2]
\`\`\`
\`\`\`

#### 生のMermaidコード

\`\`\`
flowchart LR
    A --> B --> C
\`\`\`

#### .mmdファイル（Mermaid専用ファイル）

拡張子が`.mmd`のファイルは、ファイル全体がMermaidコードとして扱われます。
コードブロック（\`\`\`）で囲む必要はありません。

\`\`\`
flowchart TD
    Start --> End
\`\`\`

`.mmd`ファイルを開くと、自動的にCodeLensとエディタタイトルバーにプレビューボタンが表示されます。

### 3. プレビューパネルの操作

- **ズームイン/アウト**: ツールバーのボタンまたはマウスホイール
- **パン（移動）**: 図をドラッグ
- **リセット**: 元のサイズと位置に戻す
- **エクスポート**: SVGまたはPNG形式でダウンロード

## インストール

### 開発版のインストール

1. リポジトリをクローン:
   \`\`\`bash
   git clone <repository-url>
   cd mermaid-preview
   \`\`\`

2. 依存関係をインストール:
   \`\`\`bash
   npm install
   \`\`\`

3. 拡張機能をコンパイル:
   \`\`\`bash
   npm run compile
   \`\`\`

4. VSCodeで開発モードで起動:
   - `F5` キーを押す
   - または、「実行とデバッグ」パネルから「拡張機能の実行」を選択

## サポートするMermaid図の種類

- フローチャート (flowchart, graph)
- シーケンス図 (sequenceDiagram)
- クラス図 (classDiagram)
- 状態図 (stateDiagram)
- ER図 (erDiagram)
- ガントチャート (gantt)
- 円グラフ (pie)
- Gitグラフ (gitGraph)
- マインドマップ (mindmap)
- タイムライン (timeline)
- その他、Mermaidがサポートするすべての図形式

## トラブルシューティング

### Mermaidコードが検出されない

- コードブロックが正しい形式（\`\`\`mermaid）で記述されているか確認してください
- カーソルがMermaidコードブロック内にあるか、コードが選択されているか確認してください
- Mermaidの開始キーワード（graph、flowchart、sequenceDiagramなど）が含まれているか確認してください

### プレビューにエラーが表示される

- Mermaidの構文が正しいか確認してください
- エラーメッセージを参照して、問題箇所を特定してください
